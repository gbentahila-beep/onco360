# Lancement du premier cabinet ami (L11, 31/10/2026)

Trois temps : la répétition générale (sans le médecin pilote), le jour J (1 h en visio avec lui), la première semaine.
Tout se fait dans Onco360 en ligne, après la mise en ligne du lot L. Aucun vrai patient pendant la répétition.

## 1. Répétition générale chronométrée (cabinet de démonstration)

Noter l'heure de début et de fin de chaque étape. But : moins de 45 minutes en tout, sans blocage.

| # | Étape | Où | Attendu | Durée notée |
|---|---|---|---|---|
| 1 | Créer un cabinet d'essai (« Cabinet répétition ») avec le pack prévu pour le pilote | Administration › Nouveau cabinet | cabinet créé, titulaire = une adresse de test | |
| 2 | Lien du mot de passe, première connexion du titulaire d'essai | Administration › fiche › Lien du mot de passe | CGU présentées, acceptées, tableau de bord | |
| 3 | Réglages du premier jour (guide, médecin page 1, points 2 à 6) | Mon compte, Paramètres | profil, un lieu, tarifs, horaires, marges | |
| 4 | Import d'un fichier fictif de 20 patients (2 doublons, 2 erreurs exprès) | Paramètres › Export des données › Importer des patients | 16 créés, numéros attribués, compte rendu Excel | |
| 5 | Premier patient créé à la main | « + Patient » | numéro de dossier attribué | |
| 6 | Une ligne de chimio, une cure validée | dossier › Chimiothérapie | fiche chimio, séance au tarif | |
| 7 | Un rendez-vous, « Venu », reçu imprimé | Agenda, salle d'attente | reçu numéroté R-AAAA-NNNN | |
| 8 | Export complet téléchargé | Paramètres › Export des données | ZIP ouvert sur l'ordinateur, patients.csv lisible | |
| 9 | Récupération d'un dossier modifié exprès (S8) | « Récupérer des données » › la base à une heure donnée | dossier remis comme avant | |
| 10 | État de la plateforme | Administration › État de la plateforme | aucune erreur nouvelle ; traitements de nuit à l'heure | |
| 11 | Supprimer le cabinet d'essai | Administration › fiche › Suspendre, puis Supprimer | export final fait, effacement prévu dans 30 jours (annulable) | |

Tout blocage : noté dans la feuille de route (« À placer ») et corrigé avant le jour J.

## 2. Jour J (1 h en visio avec le médecin pilote)

**Avant la visio (l'éditeur, 30 min avant)**

1. Modèle des cabinets neufs recopié juste avant (Administration › Par spécialité › Modèle des cabinets neufs › « Copier le cabinet du Dr Bentahila »), écart au modèle vérifié.
2. Cabinet du pilote créé (pack, mode de facturation « gratuit » pour le pilote : Administration › fiche › Abonnement).
3. Lien du mot de passe prêt à envoyer par WhatsApp.

**Pendant la visio (le médecin partage son écran)**

| Minutes | Étape |
|---|---|
| 0–5 | Lien du mot de passe envoyé, mot de passe choisi, connexion ; CGU lues et acceptées ; carte « Bienvenue » du tableau de bord. |
| 5–15 | Mon compte (nom, INPE, photo) ; Lieux d'exercice ; Activités et rémunérations (prix). |
| 15–20 | Horaires, congés ; Impression : une ordonnance d'essai imprimée, marges ajustées. |
| 20–25 | Export de la semaine activé, Google Drive du cabinet relié. Google Agenda relié (facultatif). |
| 25–30 | Messages WhatsApp : relire le modèle de rappel, l'adapter. |
| 30–40 | Patient d'essai créé (« ESSAI Patient »), une consultation, une ordonnance imprimée, un rendez-vous, « Venu », reçu ; puis le patient d'essai **supprimé**. |
| 40–50 | Compte de la secrétaire créé (Mon compte › Accès) ; lien du mot de passe envoyé ; guide de démarrage montré (menu du compte › Guide de démarrage). |
| 50–60 | Import de ses patients (si fichier prêt) ; questions ; rendez-vous fixé pour le point de fin de semaine. |

## 3. Première semaine

- **Chaque jour** : Administration › État de la plateforme (erreurs du jour, traitements de nuit) ; toute erreur nouvelle notée et corrigée.
- **Jour 2** : Administration › fiche du cabinet › « Écart au modèle » ; état du démarrage (profil, lieu, tarifs, équipe, Google Agenda, export).
- **Dimanche** : premier export de la semaine vérifié (État de la plateforme › Exports de la semaine : « OK », Drive : « déposé ») ; le ZIP ouvert une fois.
- **Fin de semaine** : point de 20 minutes avec le médecin : ce qui l'a gêné, ce qui manque ; réponses notées dans la feuille de route.
